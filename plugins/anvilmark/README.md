# AnvilMark Control Plane Plugin

Official Antigravity plugin bundling:

- **`anvilmark_project` MCP Server & MCP App (`ui://anvilmark/cockpit.html`):** Browserless local planning (`prepare_planning_context`, `lock_execution_plan`), slice execution & conformance (`list_plan_slices`, `get_slice_contract`, `verify_slice`, `record_slice_outcome`), and the interactive **AnvilMark Cockpit** inline/side-pane UI.
- **`anvilmark` Skill:** Guides conversational clarification, Empirical Bayes per-slice model routing, and strict slice-contract execution.
